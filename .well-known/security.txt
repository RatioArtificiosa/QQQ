# # Why `Expires` is set even though this file will be maintained
#
# RFC 9116 requires it, and the requirement has a purpose: a security.txt that never
# expires is one nobody re-reads, so a stale contact address stays published
# indefinitely. The date is a forcing function for a review, not a claim that the
# policy lapses.
#
# # Why there is no PGP key here
#
# A key published once and never rotated is a liability, and an unrotated key is
# worse than none because it signals a process that does not exist. Private
# vulnerability reporting through GitHub is the primary channel and is
# end-to-end encrypted; if a key is added later it will be published with a
# rotation schedule in SECURITY.md. Stating the reason is more useful to a reporter
# than a key with no provenance.
