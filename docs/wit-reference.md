### `wall-clock`

Wall-clock time, and the monotonic clock used for measurement.

# Determinism

When the host runs in deterministic mode, `now` returns a **fixed** instant
that advances only on explicit host ticks, and `resolution` reports the
virtual tick interval rather than the hardware's. A guest therefore cannot
observe wall-clock nondeterminism the host did not grant it.

**Types**

* `type instant-ns`
  Wall-clock time, and the monotonic clock used for measurement.
* `type duration-ns`
  A duration, as nanoseconds.
* `variant clock-error`
  Why a clock operation failed.

**Functions**

* `now()` → `result<instant-ns, clock-error>`
  Read the current wall-clock time.
* `resolution()` → `duration-ns`
  The smallest difference the clock can report.
* `timezone()` → `string`
  The host's configured timezone name, e.g. `UTC`.
